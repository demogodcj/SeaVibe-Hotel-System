# 🌊 SeaVibe Hotel Management System

A full-stack hotel management system built using PHP, MySQL, HTML, CSS, and JavaScript.

---

## 🚀 Features

### 👤 User
- Signup/Login
- Book Rooms
- View My Bookings
- Cancel Booking
- Payment

### 🛠️ Admin
- Dashboard
- Manage Bookings
- Payments
- Cancellations
